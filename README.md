# FORGE

FORGE — интерактивный бизнес-тренажёр для новичков, предпринимателей и тех, кто хочет прокачать бизнес-мышление.

## Version 2
- новый бренд и логотип FORGE;
- адаптивный desktop/mobile интерфейс;
- PWA-режим для установки на iPhone;
- короткие уроки;
- Business Dictionary;
- практические кейсы;
- Business Simulator;
- XP, уровни, streak и прогресс.

Публичная версия разворачивается через GitHub Pages из ветки `main`.

### iPhone
Открой сайт в Safari → Поделиться → На экран «Домой».
