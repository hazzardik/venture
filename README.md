# VENTURE

Интерактивный тренажёр бизнес-мышления: короткие уроки, словарь терминов, кейсы, XP/уровни и Business Simulator.

## GitHub Pages

В репозитории уже есть workflow публикации. После включения **Settings → Pages → Source: GitHub Actions** сайт будет автоматически публиковаться из ветки `main`.

## iPhone

VENTURE работает как PWA. Открой опубликованный сайт в Safari → **Поделиться** → **На экран «Домой»**.

Прогресс хранится локально на устройстве через localStorage.
